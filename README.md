 运行方式

  python tts_generator.py "你好，请问是张三吗？" test.mp3
  会在当前目录生成 test.mp3。第二个参数（文件名）可省略，默认生成 test.mp3。
  2. 批量生成
  先准备一个文本文件，每行一条，格式为 文字|文件名：
  你好，我是快递员，您的包裹到了|kuaidi.mp3
  您好，这边是银行信用卡中心|yinhang.mp3
  然后运行：
  python tts_generator.py -f 文本文件.txt
  如果某行没有写 |文件名，会自动命名为 test_01.mp3、test_02.mp3 …。
  3. 自定义语音
  想换其他语音（如男声、粤语等），可以修改脚本第 12 行的 VOICE 变量，比如：
  VOICE = "zh-CN-YunxiNeural"   # 男声

📌 项目简介
-----------
言犀AI助手是一个基于大语言模型和多 Agent 协作的智能电话代接系统。当机主
（用户）正在上课无法接听电话时，系统能够自动识别来电语音内容，通过 RAG
（检索增强生成）匹配预设的通话规则，再经由多个 AI Agent 协同判断风险的
等级和业务类型，最终生成合适的代接回复话术，并通过 TTS 语音合成直接播放
给来电方，实现全自动的电话代接。

系统覆盖四大来电场景：外卖配送、快递物流、亲友同学来电、诈骗推销拦截。
支持 5 级精细化风险分级（1级-安全 到 5级-高危），对诈骗电话直接拦截警告，
对营销推销礼貌拒绝，对正常业务智能处理，对亲友来电自然回应。

🔧 各程序使用方法
-----------

1. call_agent.py（主程序 - 文件选择模式）
   运行后弹出文件选择窗口，选择 MP3 音频文件即可自动处理。
   支持循环测试（处理完一个后可继续选择下一个，取消则退出）。
   会先播放原始来电语音，再生成 AI 回复语音。
   python call_agent.py

2. call_agent_mic.py（主程序 - 麦克风模式）
   运行后列出可用音频输入设备，选择后按 Enter 开始录音。
   再按 Enter 停止录音，系统自动处理并生成回复。
   输入 q 退出程序。
   python call_agent_mic.py

3. RAG_with_speech_recognition.py（基础版）
   固定读取 test.mp3 作为输入，输出 AI 回复到 ai_reply.mp3。
   适合快速测试和了解基础流程。
   python RAG_with_speech_recognition.py

4. asr_tts_test.py（语音模块测试）
   简单测试 Whisper ASR + Edge TTS 是否正常工作。
   python asr_tts_test.py

5. batch_test.py（批量测试）
   自动扫描目录下所有 MP3 文件，逐一跑完整个处理流水线。
   结果保存到 batch_test_results.json。
   注意：批量模式跳过 TTS 播放，只输出文字结果。
   python batch_test.py

6. tts_generator.py（语音生成工具）
   将文字生成为 MP3 语音文件，用于准备测试数据。
   单条模式：python tts_generator.py "来电文字" 文件名.mp3
   批量模式：python tts_generator.py -f 文本列表.txt
   文本列表格式（每行）：来电文字|文件名.mp3


🤖 多 Agent 详细说明
-----------

【DeepSceneAnalyzer - 深度场景分析 Agent】
在风险判断前先对来电内容做多维度分析：
  - 场景类别：外卖配送/快递物流/亲友来电/学校公务/营销推销等
  - 紧急程度：紧急/一般/不急
  - 话术模式：正常沟通/催促施压/恐吓威胁/利诱引导/含糊不清
  - 语义锚点：提取地点、订单号、金额、机构、时间等关键词
  - 矛盾信号：识别"声称是快递但要求转账"等异常
  - 信息完整度：信息是否足以做出判断

【RiskControlAgent - 风险防控 Agent（增强版）】
5 级风险分级系统（严格执行铁律规则）：
  5级-高危：明确诈骗（转账/验证码/冒充公检法/安全账户）
    → 拦截，话术示例："你正在进行的是诈骗行为，已全程录音并报警"
  4级-高风险：高度疑似诈骗（恐吓+矛盾信号/冒充配送员无订单信息）
    → 拦截，话术示例："机主不需要相关服务，请勿再次来电"
  3级-中风险：营销推广/品牌促销/广告推销
    → 拒绝，话术示例："您好，机主不需要相关服务，请勿再次来电"
  2级-低风险：身份不明/信息不足/亲友借钱等需机主自行判断
    → 转人工
  1级-安全：为已有订单服务的正常配送/取件/售后/亲友来电
    → 流转业务处理

  重要规则（关键词兜底修正）：
  - "补差价/拼好饭没了" → 强制1级（订单异常处理，不是营销）
  - "借钱" → 不高于2级（正常人际交往，转人工）
  - 亲友来电必须判1级（除非有诈骗信号）

【BusinessProcessAgent - 业务处理 Agent（增强版）】
处理正常来电的代接回复，覆盖多种场景：

  外卖场景：
  - 正常送达 → "您好，机主正在上课，放在北门就行，谢谢"
  - 菜品售罄 → 自动同意换同价位套餐
  - 配送延迟 → 确认知晓，同步给机主
  - 找不到地址 → 给出指引或同意替代位置
  - 补差价/退款 → 自动同意
  - 餐品洒漏 → 同意重做或退款
  - 外卖柜故障 → 同意放置在替代位置

  快递场景：
  - 正常派送 → "好的收到，机主会尽快去取，谢谢提醒"
  - 超时退回提醒 → 确认机主会尽快取件
  - 破损/丢失 → 告知同步机主处理
  - 货到付款 → 确认可 APP 支付
  - 上门取件 → 确认预约时间
  - 二次派送 → 建议放驿站/快递柜

  亲友场景（核心规则：假装是机主本人）：
  - 来电"什么时候回来吃饭" → "爸，我正上课呢，下课就回家"
  - 来电"生日快乐" → "谢谢！我正上课，下课给您回电话"
  - 根据来电内容智能判断称呼（妈/爸/奶奶/二姨/同学等）

【ManualTransferAgent - 人工转接 Agent】
处理无法自动处理的来电：
  - 风险无法判断
  - 业务无法自动处理
  - 来电人明确要求转人工
  话术示例："已记录您的信息，机主下课后会第一时间给您回电"


📊 风险判断铁律（4条不可违反的规则）
-----------
铁律1：1级-安全场景必须判1级，不可升级
  - 外卖配送/异常处理、快递配送、亲友来电 → 只要不要求转账/验证码

铁律2：亲友来电必须判1级
  - 父母/爷爷奶奶/男女朋友/同学/室友 → 都是1级
  - 朋友借钱/借笔记/约打球 → 都是1级（正常人际交往）
  - 只有出现"转给我/打钱到XX账户/提供验证码/点击链接"才升级

铁律3：推销不是诈骗
  - 房产/保险/课程/信用卡/理财/健身房 → 3级-中风险，不是5级
  - 只有索要密码/验证码/转账到个人账户才升级为5级

铁律4：订单异常处理不是营销
  - 补差价/餐洒重做/缺货换套餐 → 1级-安全，不是3级营销
  - 处理已有订单问题 = 1级；想让机主买新东西 = 3级


🔑 核心规则
-----------
1. 所有回复话术都是直接播放给来电方听的——你是替机主接电话的人
2. 机主当前状态：正在上课，无法接听电话
3. 严禁出现"麻烦您取餐/取件"——配送员是送的人，不是取的人
4. 对亲友来电要假装是机主本人，不要扮演"同学/室友"
5. "转接人工"的意思是转告机主，不是转给客服中心
6. 外卖/快递异常场景可自动决策，无需等机主确认
7. 回复内容必须对应来电场景，严禁模板混用


📈 批量测试结果
-----------

  - 风险等级和类型
  - 处理动作（拦截/拒绝/转人工/流转业务处理）
  - 最终 AI 回复话术


⚠️ 注意事项
-----------
1. 首次运行 Whisper 会自动下载模型文件（几百MB到几GB不等）
2. Edge TTS 需要网络连接（调用微软在线语音合成服务）
3. 智谱AI API 调用需要网络连接和有效的 API Key
4. Windows 系统下使用 asyncio.WindowsSelectorEventLoopPolicy() 兼容
5. 知识库文件 knowledge.txt 必须与程序同目录
6. API Key 已硬编码在程序中，实际部署建议替换为环境变量读取
7. 推荐使用 .venv 虚拟环境运行
